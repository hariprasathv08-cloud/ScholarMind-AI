# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/hariprasathv08-cloud/ScholarMind-AI.git
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Run backend

```bash
uvicorn main:app --reload
```
